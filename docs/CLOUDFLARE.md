# Cloudflare Pages deployment
Deploy only the synthetic public preview, not the local Node/SQLite/Ollama server or mobile TLS gateway. In Cloudflare dashboard > Workers & Pages > Create application > Pages > Connect to Git, authorize the repository Joseyosei/HomeSpehere-AI. Project name homesphere-ai (subject to availability); production branch main; framework preset None; build command blank; root directory preview; build output directory . (current directory). No environment variables, databases, functions, or secrets required. If leaving root directory blank instead, set output directory preview. Save and Deploy. Use the exact pages.dev URL reported by Cloudflare; do not assume the name is available. Keep Vercel available independently. _headers applies security headers to static assets; 404.html prevents fallback from pretending private API paths exist. After deploy check /, /manifest.webmanifest, /sw.js, /api/health (must return 404), and exercise the simulated assistant. Never expose actual household APIs or forward router ports for this demo.
