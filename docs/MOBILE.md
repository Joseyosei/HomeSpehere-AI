# Stage 14 mobile foundation
Expo SDK 58 / React Native 0.88.1 / React 19.3.0. One native source project under mobile/. Five tabs, system theme, synthetic readings, example energy costs/chart, device list, rule-based demo assistant and HTTPS gateway status probe. No real authentication or control from mobile yet; no credentials collected. Gateway is not yet implemented: existing loopback API rejects remote host/origin. Do not bind it to all interfaces or forward router ports. Future stage must implement trusted TLS, pairing, scoped/revocable native tokens and household checks. Bundle IDs provisional; verify ownership before store submission.
## Mac
Install Node 22 LTS (>=22.13), Git, Xcode and simulator components, Android Studio SDK/emulator, compatible JDK per Expo SDK 58 docs. From repository: cd mobile; npm install; npm run test; npx expo install --check; npx expo start. Choose iOS or Android simulator. Expo Go may require an SDK-compatible version; local development builds via npx expo run:ios or run:android after environment setup. Native builds not verified in CI; export is JS bundle validation only. Apple developer signing and Play Console setup later. Mac can build both platforms.
## Home
Install Home Assistant on dedicated hardware or a supported VM; connect a compatible sensor/energy-monitoring plug. Use actual sensor entity ID and trusted TLS. Configure root .env using docs/INTEGRATIONS.md; never paste secrets into chat or commit. Start root npm run start:configured; sign in at http://127.0.0.1:8780, select live. Plug measures that appliance, not whole-home demand. Mac must remain awake while serving; dedicated always-on host recommended for long-term use. Vercel preview is synthetic only.
