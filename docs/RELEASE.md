# Stages 11–13 release package
Stage 11: SQLite online snapshot and integrity check, restore drill, synthetic performance benchmark, Node regression suite and Chromium UI suite. npm audit --omit=dev is a dependency advisory check, not a penetration test. Restore with server stopped: back up existing database, move existing database plus WAL/SHM files aside, copy verified snapshot to configured DB_PATH, restrict permissions, restart (automation disarms). Backups contain credentials hashes and private readings: never upload them. Revoke all sessions after recovery if needed. Benchmark is a small synthetic fixture, not a production capacity guarantee.
Stage 12: deploy preview/ only as static Vercel or Cloudflare Pages site, no backend/ or private data. Vercel root directory preview, Other framework, no install/build, output .; Cloudflare Pages static output preview. Public demo uses only synthetic browser data and simulated actions. Real local app still runs Node 22 with SQLite, MQTT, HA and Ollama; do not publish the localhost API. Secure LAN gateway, trusted TLS, device pairing, native mobile authentication and production penetration testing remain required. No cloud persistence or remote control.
Stage 13: proposed commercial tiers Local free, Plus £4.99/month, Household £9.99/month. Pricing hypotheses not validated; no payment collection, entitlement enforcement, or actual subscription. Hobby preview is non-commercial; review host plan terms before selling. Validate demand via opt-in interviews, test pricing, define support and privacy policy, review data protection requirements, then build actual billing and entitlements. No customer accounts or data on hosted demo.
Mobile roadmap: native iOS and Android (shared React Native/Expo UI), secure pairing to local gateway, scoped device tokens, local network permissions, offline shell, accessibility and store testing. Never embed HA or admin tokens in mobile code.
