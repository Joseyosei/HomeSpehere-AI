# Database
Node 22.13+ built-in node:sqlite, synchronous API, local single-household workload. Database defaults to data/homesphere.sqlite (ignored by Git); DB_PATH overrides. WAL and foreign keys enabled. Schema migration 1 is transactional via PRAGMA user_version; future version rejected. Tables: households, rooms, devices, readings. Room belongs to household; device must share room household; reading belongs to device. Source demo/live belongs to device. Never attach real readings to a demo device. Primary key (device_id, metric, ts) deduplicates; conflict preserves first value. Quality good/missing/suspect; null only for missing. Metric/unit and physical bounds constrained. Timestamps in UTC milliseconds. SQLite files contain private data; restrict file permissions and keep backups outside Git. Stop server before copying database, or use SQLite backup tooling; don't copy just main file while WAL active. No automatic retention yet; future ingestion requires retention policy and authenticated adapter. No tenant security claim: household filter is not authorization.
